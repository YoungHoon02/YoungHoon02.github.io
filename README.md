# Crafting Pills

게임 모드, 개인 프로젝트, 개발 기록을 소개하는 포트폴리오입니다.

사이트: [pills02.dev](https://pills02.dev)

## 로컬 실행

Node.js 22와 npm을 사용합니다.

```sh
npm ci
npm run dev
```

배포용 빌드와 로컬 미리보기:

```sh
npm run build
npm run preview
```

## 콘텐츠 관리

프로필, 포트폴리오 저장소, 게임별 프로젝트, 안내 문구는 `src/data.js`에서 관리합니다. GitHub에는 포트폴리오로 공개할 프로젝트만 직접 등록하며, 취미 프로젝트는 등록하지 않습니다. 게임 모드와 취미 프로젝트는 Game에서 소개합니다. 저장소를 API로 자동 수집하지 않습니다. 사용 언어 태그는 `LangTag`로 표시하고, 창작마당 모드는 `Steam Workshop` 태그를 사용합니다.

## Notes 작성

Notes에는 개발 중 겪은 문제, 선택의 이유, 시행착오 등 개발 비화를 기록합니다.

저장소 최상위 `notes/`에 Markdown 파일을 추가합니다. 파일명은 글 주소의 slug가 됩니다. 영문 소문자·숫자·하이픈을 사용하면 주소를 관리하기 쉽습니다.

예를 들어 `notes/my-first-note.md`의 상단에 다음 내용을 작성합니다.

```md
---
title: 첫 개발 기록
date: 2026-09-30
---

본문을 Markdown으로 작성합니다.
```

목록은 날짜 최신순이며, 이 글의 주소는 `https://pills02.dev/#/notes/my-first-note`입니다. 제목과 날짜는 한 줄씩 작성하고 날짜 형식은 `YYYY-MM-DD`를 사용합니다. 글 목록 등록은 필요하지 않으며, 새 글을 사이트에 반영하려면 다시 빌드·배포합니다.

본문의 HTML은 문자로 표시됩니다. 링크와 이미지에는 일반적인 HTTPS 주소를 사용하세요.

## 게임 이미지와 모드 썸네일

게임 헤더는 Steam CDN에서 직접 불러옵니다. 모드 썸네일은 최상위 `img/`에 넣으면 자동으로 수집됩니다.

프로젝트 이름을 소문자로 바꾸고 영문 소문자·숫자가 아닌 문자를 하이픈 하나로 치환한 뒤, 앞뒤 하이픈을 제거한 값이 파일명과 일치해야 합니다.

| 프로젝트 이름 | 썸네일 파일 예시 |
| --- | --- |
| Battle Log | `img/battle-log.webp` |
| Anim Speed Tweak | `img/anim-speed-tweak.webp` |
| Metro Genesis KR Localisation | `img/metro-genesis-kr-localisation.webp` |

지원 확장자는 `webp`, `png`, `jpg`, `jpeg`, `gif`입니다. 같은 이름에 확장자만 다른 파일을 두 개 두지 않습니다. 프로젝트 이름을 변경하면 파일명도 함께 변경합니다. 한글만으로 된 이름은 이 규칙으로 매칭되지 않습니다. 썸네일이 없다면 이미지 없이 표시됩니다.

권장 비율은 3:1, 크기는 600×200입니다. 이미지는 원본 비율을 유지하며 가운데를 기준으로 잘라 채웁니다. 움직이는 WebP는 5~10초 루프, 12~15fps, 품질 50~65, 파일당 1~2MB 이하를 권장합니다. 호버와 무관하게 계속 재생되므로 중간 장면부터 보일 수 있습니다.

## 라우팅과 배포

홈은 `/`, 하위 페이지는 `#/github`, `#/game`, `#/notes`, `#/notes/{slug}`를 사용합니다. GitHub Pages의 하위 경로 새로고침 404를 피하기 위해 해시 라우팅을 유지합니다.

`main`에 push하면 GitHub Actions가 빌드 후 Pages에 배포합니다. 커스텀 도메인은 GitHub Pages 설정에서 관리하며 저장소에는 CNAME 파일을 추가하지 않습니다.

사이트 제목·설명·공유 미리보기 정보는 `index.html`에서 관리합니다. 해시 라우팅을 사용하는 정적 사이트이므로 공유 정보는 모든 페이지에서 공통입니다.
